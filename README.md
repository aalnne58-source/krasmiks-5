# КраскаМикс

Интернет-магазин лакокрасочных материалов и оборудования для кузовного
ремонта. React + React Router + Context API, каталог с фильтрами, корзина
на localStorage.

## Запуск

```bash
npm install
npm run dev
```

Откроется адрес из вывода Vite (обычно http://localhost:5173).

Сборка для продакшена:

```bash
npm run build
npm run preview
```

## Структура проекта

```
src/
  components/     # Header, Footer, ProductCard, CategoryCard, Filters, CategoryIcon
  pages/          # Home, Catalog, Product, Cart, Contacts
  context/        # CartContext (React Context API + localStorage)
  data/           # products.js — каталог товаров
  styles/         # глобальные CSS-переменные и базовые стили
```

## О данных каталога

Товары в `src/data/products.js` собраны из реальных прайс-листов поставщиков,
предоставленных пользователем:

- **JETA PRO** — ЛКМ (лаки, грунты, шпатлевки, клей/герметики, аэрозоли),
  оборудование (краскопульты, шлифовальные машинки, фонари), расходные
  материалы (маскирующая пленка, лента, тест-пластины).
- **MIPA** (из прайса клиента «Шикарная И.В.») — автомобильные акриловые
  эмали и аэрозольные краски.
- **Menzerna** — полировальные пасты и диски.
- **Walmec** — профессиональные краскопульты.
- **3M** (из того же прайса) — малярная лента и абразивные круги.

Цены приведены в рублях. Позиции, заданные в прайсах в EUR, пересчитаны по
курсу ≈100 ₽/€ — это ориентировочный курс, перед запуском в продажу
замените его на актуальный или подключите к прайсам напрямую.

**Важно:** ассортимент поставщиков — это материалы и оборудование для
**авторемонта и покраски автомобилей** (автоэмали, кузовные шпатлевки,
краскопульты), а не для отделки помещений (интерьерные краски, обои и т.п.,
как в примере Петровича). Категории и товары в каталоге отражают именно
этот, реальный ассортимент. Фотографий товаров в прайсах не было — вместо
фото используются простые SVG-иконки по категориям (`CategoryIcon.jsx`);
замените их на реальные фотографии товаров, когда они появятся.

## Что можно добавить дальше

- Подключить реальный backend/CMS вместо статического `products.js`.
- Добавить актуальный курс валют (API ЦБ РФ) для пересчёта цен из EUR.
- Добавить фотографии товаров.
- Подключить форму/корзину к реальному оформлению заказа (сейчас кнопка
  оформления ведёт на звонок по телефону).
